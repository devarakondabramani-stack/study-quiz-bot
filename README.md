# Study Quiz Bot

An AI-powered Telegram quiz bot built using n8n automation and Groq AI.

## Features
- Accepts study notes or PDF documents through Telegram.
- Generates multiple-choice quiz questions.
- Checks submitted answers automatically.
- Calculates the score and provides explanations.
- Sends quiz results through Telegram and email.

## Technologies Used
- n8n
- Telegram Bot API
- Groq AI
- SMTP Email

## Workflow
1. Send study notes or a PDF to the Telegram bot.
2. The bot generates a quiz.
3. Submit your answers in one message.
4. Receive your score and corrections.
5. Get the results by email.

## Project Status
Successfully tested.

## Security
Credentials and API keys are stored separately in n8n. Never share them publicly.
